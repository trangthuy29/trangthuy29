### 📐 How I work

1. Start from a business question, not from the dataset
2. Document every row dropped during cleaning
3. Report the median next to the mean when the distribution is skewed
4. Separate association from causation — and say so in writing
5. Close with limitations; descriptive analysis stays descriptive
